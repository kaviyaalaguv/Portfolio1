Project Overview

Role: Graphic Designer Intern
Company: United Hotel Supply
Project Type: Commercial Seating Spec Sheets / Hospitality Marketing Collateral
Responsibilities: Layout composition, grid alignment, image placing, technical specification typography, and compliance standards formatting.

The Brief

The objective was to create clean, high-impact product spec sheets for commercial hospitality furniture, specifically targeted at guestrooms, lounges, and suites. Each sheet needed to clearly communicate product dimensions, frame suspension details, material options, and compliance standards to hotel developers and interior design buyers.

The Design Challenge

Balancing full-bleed interior render visualizations with dense technical specifications required a strict layout grid. The challenge was ensuring that key dimensions (Length, Width, Height) and structural parameters (Kiln-Dried Hardwood, High-density foam, CAL TB117-2013 compliance) were readable at a glance without overpowering the hero furniture visual.

My Role & Responsibilities

• Structured two-panel layout split: 50% lifestyle visual render and 50% data specification grid.
• Formatted high-contrast blue header blocks displaying collection title and specific item SKU codes.
• Designed prominent 3-metric specification callout boxes for key physical dimensions.
• Organized technical details (frame, suspension, cushioning, base finish, compliance) into structured 2-column tabular views.
• Maintained consistent branding, contact info footer, and production alignment across all sheets.

01 — Courtyard Dove Sofa Sleeper (Right Arm Facing / ALT4)

This spec sheet highlights the Courtyard Dove Sofa Sleeper (SKU: X-239R-WH-ALT4). Designed with a light neutral aesthetic, the layout balances the warm architectural background with a clear 64" W × 41.25" D × 63" H specification block and highlighted kiln-dried hardwood specifications.

02 — Courtyard Navy Sofa Sleeper (Right Arm Facing / ALT6)

Demonstrating dark fabric variant presentation, this sheet features the Courtyard Navy Sofa Sleeper (SKU: X-239R-WH-ALT6). The deep navy header complements the dark upholstery visual, maintaining precise baseline grid alignment for technical details.

03 — Courtyard Dove Sofa Sleeper (Left Arm Facing / ALT4)

This layout variant covers the Left Arm Facing configuration (SKU: X-239L-WH-ALT4). The side-by-side comparison ensures architectural buyers can quickly verify structural orientation alongside exact dimensional specs.

04 — Courtyard Navy Sofa Sleeper (Extended Length Variant)

Showing dynamic dimension adjustment, this layout accommodates an extended 71" Length specification while keeping all secondary material parameters, base finish options, and joinery details strictly aligned with the rest of the series.

05 — Garner Warm Sofa (Armchair Accent View)

Adapted for standalone lounge seating, this sheet features the Garner Warm Sofa armchair (29" L × 32" W × 32" H). The layout maintains brand consistency across different furniture categories while highlighting textured upholstery options.

What I Learned

• Technical specification sheets demand complete typographic consistency across variable metrics.
• Standardizing layout templates speeds up production while keeping client presentations cohesive.
• Highlighting commercial compliance standards (such as CAL TB117-2013) is essential for B2B hospitality collateral.

Professional Takeaway

Working on United Hotel Supply's seating program strengthened my skills in structural layout systems, B2B product presentation, and balancing aesthetic visuals with critical technical specifications.
